# FileCompare

Windows、macOS、Ubuntu で動作する、ファイルおよびディレクトリ比較用のコンソールアプリです。C++20 と CMake を使用しています。

## 機能

- ファイル同士を比較し、内容が同じかどうかを表示します。
- ディレクトリ同士を比較し、直下の項目の差分を表示します。`-r` を指定するとサブディレクトリも比較します。
- `-s` を指定すると、一致したファイルや「差分なし」の表示を省略します。
- 両方のパスが存在することと、比較対象の種類（ファイルまたはディレクトリ）が一致することを確認します。
- Windowsではコンソールの入出力コードページをUTF-8に設定します。

ファイル内容の比較には64ビットFNV-1aハッシュを使います。ディレクトリ比較では項目名と種類を確認し、同じ相対パスのファイルはハッシュで内容を比較します。既定では直下のみを比較します。

## 必要なもの

- C++20 に対応したC++コンパイラ
- CMake 3.10以降
- Ninjaなど、CMakeで利用できるビルドツール

## ビルド

プロジェクトのルートディレクトリで以下を実行します。

```sh
cmake -S . -B build
cmake --build build
```

実行ファイルは、使用するジェネレーターや構成に応じて `build` 以下に作成されます。Visual Studioから開く場合は、CMakeプロジェクトとしてこのディレクトリを開いてビルドしてください。

## 使い方

引数に比較する2つのパスを指定します。パスに空白が含まれる場合は引用符で囲みます。

```text
FileCompare [-r] [-s] <パス1> <パス2> [-r] [-s]
```

`-r` と `-s` はパスの前後どちらにも置けます。`-r` はディレクトリ比較に、`-s` はファイル・ディレクトリ比較のどちらにも指定できます。

### ファイル比較

```sh
FileCompare ./left.txt ./right.txt
```

一致した場合の出力を省略する場合:

```sh
FileCompare -s ./left.txt ./right.txt
```

出力例:

```text
一致: ./left.txt == ./right.txt
```

異なる場合は `相違:` と両方のパスを表示します。

### ディレクトリ比較

```sh
FileCompare ./left-directory ./right-directory
```

サブディレクトリも含める場合:

```sh
FileCompare -r ./left-directory ./right-directory
```

一致項目を表示せず差分だけ表示する場合:

```sh
FileCompare -r -s ./left-directory ./right-directory
```

出力例:

```text
左のみ: ./left-directory/only-left.txt
右のみ: ./right-directory/only-right.txt
相違: ./left-directory/shared.txt | ./right-directory/shared.txt
```

同じ相対パスの項目が両方にあり、種類とファイル内容も同じ場合、その項目は出力しません。差分がなければ `差分はありません。` と表示します。

## 終了コード

- `0`: 比較処理が完了しました（差分の有無は問いません）。
- `1`: パス、読み込みなどのエラーです。
- `2`: 引数の数が正しくありません。比較対象のパスを2つ指定してください。
